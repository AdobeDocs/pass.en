### Release Overview {#release-overview-380}

This release focuses on stability, enhancements and security updates across Adobe Pass Authentication services.

#### Bug Fixes

* Fixed an issue that caused HTTP 500 errors on V2 APIs due to certain invalid characters in the deviceId.

#### Enhancements

* Improved refresh token handling to support rolling token renewal.
* Enhanced visitorId recognition on secondary devices for analytics.
* Enhanced URL parameter validation to strengthen security controls and improve overall system integrity.
* TVE Dashboard version 1.5.2 with minor UI improvements.
